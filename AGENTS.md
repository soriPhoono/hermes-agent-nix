# AGENTS.md

Rules for agents working in this repository.

## Layout

- `modules/` — flake-parts modules. `default.nix` exports `nixosModules` and
  `homeManagerModules`. `inputs.nix` declares flake inputs.
- `modules/_lib/` — shared helpers (profile options, renderer). The underscore
  keeps them out of module auto-wiring.
- `flake-system/` — flake-parts plumbing: dev shell, treefmt, pre-commit, systems.
- `flake.nix` is generated by flake-file. Declare inputs in `modules/inputs.nix`,
  then run `nix run .#write-flake`. Never edit `flake.nix` by hand.
- `.pre-commit-config.yaml` is generated and gitignored.

## Rules

- Never decrypt, edit, or re-encrypt SOPS secrets. Secret files are referenced by
  runtime path (`config.sops.secrets."x".path`), never copied into the Nix store.
- Do not activate or deploy anything. Report checks and hand off.
- Conventional Commit prefixes, one logical change per commit.
- `configMergeScript.nix` is read from the locked `hermes-agent` input. It is an
  upstream-internal path, so a bump of that input needs a re-run of the checks.

## Verification

```bash
nix run .#write-flake && git diff --exit-code flake.nix
nix flake check -L
nix build .#checks.x86_64-linux.<check> -L
```

`nix flake check` alone does not prove a consumer builds; build the named checks.
